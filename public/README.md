## 💻 How to Run Locally

You can preview the website immediately in two ways:

### Option 1: Direct File Opening
Double-click `index.html` in your file explorer to open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000) in your browser.

Or using Node:
```bash
npx serve .
```

## 🌐 Deployment Guide for Nepal

This website is completely self-contained (zero heavy framework dependencies or complicated build steps), which means it can be deployed in minutes on any hosting platform:

1. **cPanel / Shared Hosting (Standard in Nepal):**
   - Connect to your cPanel File Manager or FTP.
   - Upload all files (`index.html`, `css/`, `js/`, `assets/`) into the `public_html/` directory.
   - Your site will be live immediately on your domain!
2. **Free Hosting via GitHub Pages:**
   - Create a GitHub repository and push this directory.
   - Go to **Settings** > **Pages** > Select branch `main` and root `/`.
   - Your site will be published at `https://<username>.github.io/<repo>/` or your custom domain.
3. **Vercel or Netlify:**
   - Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
   - Instant deployment with free SSL certificate and worldwide CDN caching.
